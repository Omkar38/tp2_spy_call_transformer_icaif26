\section{Setup}

This report is for the separate no-ML comparison strategy:

\begin{itemize}
  \item Test year: 2024 only
  \item Strategy: \texttt{T1}
  \item Trade rule: trade every valid/labeled 2024 \texttt{T1} violation row
  \item Gross exposure: \$1,000 per accepted trade
  \item Input file: \texttt{reports/t1\_all\_violations/t1\_all\_2024\_valid\_trades.csv}
\end{itemize}
